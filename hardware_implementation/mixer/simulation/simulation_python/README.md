This project translates the Mixer simulation, which is currently written in Octave, into Python.

# Python setup

- suggestion: use a virtual environment (https://docs.python.org/3/tutorial/venv.html)
	- create venv: python3 -m venv .venv
	- activate venv: source .venv/bin/activate
- install requirements: pip install -r requirements.txt
- run application: python3 app.py
