These scripts simulate an early version of the Mixer protocol.

# Structure

## GFarithmetic.m
- mathematical operations for Mixer

## Mixer.m
- Mixer protocol logic

## testbedTools.m
- UI and logic to generate testbeds
- can be executed
- contains link model to simulate packet receptions

## testcaseTools.m
- UI and logic to run protocol logic (Mixer) on a testbed
- contains further functionality to replay tests, and evaluate and plot trace (log) files
- can be executed
